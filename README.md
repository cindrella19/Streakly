Streakly – Build Better Habits, One Day at a Time
    Streakly is a thoughtfully designed Android habit-tracking application that helps users build discipline and consistency by maintaining daily streaks. The app focuses on simplicity, motivation, and reliability, allowing users to track habits effortlessly while keeping their progress secure through cloud-based authentication.The goal of Streakly is to encourage positive behavior through consistency. By visualizing streak progress and making habit tracking simple, the app helps users stay focused on long-term self-improvement.
Key Features
Secure User Authentication
    Streakly provides a secure and seamless login experience using Email and Password authentication as well as Google Sign-In. Firebase Authentication is used to manage user sessions, ensuring that user data remains private and protected.
Habit and Streak Tracking
    Users can create daily habits and track their streaks over time. The app emphasizes consistency by helping users visualize their progress and stay motivated to maintain uninterrupted streaks.
Clean and User-Friendly Interface
    The app is built using Material Design principles, offering a clean, minimal, and distraction-free interface. The layout is designed to be intuitive so users can focus on building habits rather than learning complex controls.
Cloud-Ready Backend Architecture
    Firebase is integrated into the app to handle authentication and future cloud data storage. The architecture is designed to be scalable, allowing features like data syncing and backup to be added easily in the future.
Professional Version Control
    The entire project is managed using Git and GitHub. This ensures proper version control, code history tracking, and collaboration readiness, following industry-standard development practices.
Technology Stack
    Programming Language: Java
    User Interface: XML
    IDE: Android Studio
    Backend Services: Firebase
    Authentication: Firebase Authentication using Email and Google
    Version Control: Git and GitHub
Firebase Integration
    Firebase is used in Streakly to manage user authentication and login sessions securely. The app connects to Firebase services to ensure that each user’s data remains isolated and protected.Sensitive configuration files such as google-services.json are intentionally excluded from the public repository to maintain security and follow best development practices.
Project Structure
    The project follows a standard Android Studio structure.
    The app directory contains all application source code and resources.
    Gradle files manage build configuration and dependencies.
    Git ignore rules are applied to prevent sensitive or auto-generated files from being uploaded.
How to Run the Project
    Clone the project repository from GitHub.
    Open the project in Android Studio.
    Create a Firebase project and add your own google-services.json file.
    Enable Email and Google authentication in the Firebase Console.
    Sync Gradle and run the app on an emulator or physical Android device.
Academic Objective
    This project was developed for academic purposes to demonstrate practical Android application development using Java. It showcases Firebase Authentication integration, cloud-ready architecture, clean UI design, and professional version control using GitHub.The project reflects real-world development practices and serves as a strong foundation for future enhancements.
